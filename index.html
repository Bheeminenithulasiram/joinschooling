01 · System Architecture

How the pieces fit together

Edge-rendered Next.js speaks JWT to a FastAPI monolith backed by PostgreSQL and Redis. Long-running work (email, AI scoring, reports) is offloaded to Celery.

┌────────────────────────┐ │ Cloudflare CDN │ └───────────┬────────────┘ │ ┌───────────────▼────────────────┐ │ Next.js 15 · Vercel Edge │ │ RSC · ShadCN · TanStack Q │ └───────┬────────────────────────┘ │ HTTPS · JWT (Bearer) ▼ ┌────────────────────────────────┐ ┌──────────────┐ │ FastAPI · Railway / Render │◀──▶│ Redis (cache │ │ REST · OpenAPI · OAuth2 │ │ + rate-limit │ │ SQLAlchemy · Pydantic v2 │ │ + broker) │ └──────┬──────────────┬──────────┘ └──────────────┘ │ │ enqueue ▼ ▼ ┌────────────────┐ ┌────────────────┐ │ PostgreSQL 15 │ │ Celery Worker │ │ Neon / Supabase│ │ email · AI │ └────────────────┘ │ finder · PDF │ └───────┬────────┘ ▼ ┌────────────────┐ │ Cloudinary │ │ (media store) │ └────────────────┘
1

RSC-first frontend

SEO-heavy pages (landing, college/internship listings & details, blogs) stream from the edge as React Server Components. Interactive pages hydrate with TanStack Query for cache-first UX.

2

JWT + rotating refresh

15-min access, 30-day refresh with server-side revocation via refresh_tokens table. Role enum on users drives require_role() deps.

3

Redis + Celery

Cache-aside for public GETs, token-bucket rate limits, Celery broker for OTP delivery, AI Finder scoring, and PDF/CSV exports.

4

Postgres-native search

pg_trgm + GIN indexes cover college / internship / company search up to ~100k rows before we graduate to OpenSearch.

Colleges table (excerpt)

DDL 
CREATE TABLE colleges (
  id               UUID  PRIMARY KEY DEFAULT uuid_generate_v4(),
  name             VARCHAR(200)  NOT NULL,
  slug             VARCHAR(220)  NOT NULL UNIQUE,
  type             college_type    NOT NULL,   -- enum
  state            VARCHAR(80)   NOT NULL,
  city             VARCHAR(80)   NOT NULL,
  naac_grade       VARCHAR(5),
  nirf_rank        INT,
  avg_package_lpa  NUMERIC(6,2),
  highest_package_lpa NUMERIC(6,2),
  placement_percent   NUMERIC(5,2),
  hostel_available BOOLEAN NOT NULL DEFAULT FALSE,
  infrastructure   JSONB NOT NULL DEFAULT '{}'::jsonb,
  facilities       TEXT[],
  rating           NUMERIC(3,2)   NOT NULL DEFAULT 0,
  created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
  deleted_at       TIMESTAMPTZ
);
CREATE INDEX idx_colleges_state_city  ON colleges(state, city);
CREATE INDEX idx_colleges_name_trgm   ON colleges USING gin (name gin_trgm_ops);
CREATE INDEX idx_colleges_avg_package ON colleges(avg_package_lpa DESC);

Applications (polymorphic)

DDL 
CREATE TABLE applications (
  id           UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  student_id   UUID NOT NULL REFERENCES students(user_id) ON DELETE CASCADE,
  target_kind  VARCHAR(20) NOT NULL,
    -- 'internship' | 'college' | 'scholarship' | 'hackathon' | 'workshop'
  target_id    UUID NOT NULL,
  status       application_status NOT NULL DEFAULT 'submitted',
  cover_letter TEXT,
  resume_url   TEXT,
  answers      JSONB NOT NULL DEFAULT '{}'::jsonb,
  reviewed_by  UUID REFERENCES users(id),
  reviewed_at  TIMESTAMPTZ,
  submitted_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(student_id, target_kind, target_id)  -- idempotent apply
);
Soft deletes

deleted_at on business tables; hard delete for tokens/OTPs.

Audit fields

Auto-touched updated_at via touch_updated_at() trigger.

Fuzzy search

GIN + gin_trgm_ops on names, titles, skills, tags.

Enums

user_role, work_mode, application_status, saved_kind, college_type.

04 · REST API

A clean, consistent contract

Versioned under /api/v1. Bearer JWT. Uniform pagination & error envelope. Full spec generated at /docs via FastAPI.

Auth

Authorization: Bearer <access> · refresh via /auth/refresh · rotating refresh tokens with server-side revocation.

Pagination

?page=&page_size= → {items, pagination:{total,has_next}} · max 100/page.

Errors

RFC 7807 application/problem+json with errors[] for 422s.

Rate limits

60/min anon · 300/min user · 10/min on /auth/*. Token-bucket in Redis.

Cache

Public GETs 60s Redis + stale-while-revalidate=300.

Docs

/docs Swagger · /redoc · /openapi.json → typed FE via openapi-typescript.

07 · Security

Zero-trust defaults

  • • Argon2id password hashing
  • • JWT RS256 with key rotation
  • • Rotating refresh tokens
  • • Redis token-bucket rate limits
  • • Pydantic strict validation
  • • ORM = no SQL injection
  • • Bleach-sanitized markdown
  • • CORS allowlist per env
  • • Every mutation → activity_log
  • • HTTPS-only + HSTS
08 · Performance

Fast where it matters

  • • Next.js RSC + edge streaming
  • • next/image AVIF/WebP
  • • Route-level ISR (revalidate=300)
  • • Skeleton + optimistic UI
  • • SQLAlchemy selectin loads
  • • Redis cache-aside 60s
  • • Pool 20 + overflow 30
  • • Composite & GIN indexes
  • • Materialized rating aggregate
  • • PWA + service-worker precache
